# 亚马逊账号申诉

## 何时使用本技能

在卖家**收到停用/限制通知**或准备向 **Seller Performance / 账户状况相关团队** 提交**申诉、行动计划（POA）或恢复使用权说明**时使用。本技能生成**英文为主**的正文草稿（亚马逊审核常用英文）；并附**中文摘要**便于内部审阅。**通过与否由亚马逊单方决定**，本稿不承诺结果。

## 输入项（与表单一致）

| 字段 | 必填 | 说明 |
|------|------|------|
| **亚马逊账号** | 是 | 用于标识店铺：如**店铺显示名**、卖家记号、或**脱敏后的注册邮箱**（勿在长对话中粘贴完整密码、完整信用卡号）。若用户仅填此项，正文用 **[待补充：停用原因原文 / 通知日期 / 涉及 ASIN 或政策条款]** 等占位符列出缺口。 |

**一键粘贴模板**：

```
亚马逊账号（必填）：
```

**强烈建议用户在同一条消息中补充**（不必单独做表单项，但技能应引导）：停用邮件要点、日期、被指违规类型、已采取的纠正措施—信息越多，POA 越可落地。

## 核心原则

1. **承担责任与事实**：避免空喊冤枉；按用户**真实陈述**整理根因—若用户未说明原因，稿内写「待根据绩效通知逐条对应」并列出问题清单供用户回填。
2. **POA 常见结构**（视违规类型裁剪）：
   - **Opening**：账号标识、礼貌请求复审。  
   - **Understanding**：对政策理解的简短重述（不捏造未读过的条款编号）。  
   - **Root cause**：分条说明**直接原因**（供应链、运营、列表、物流、买家体验等）。  
   - **Immediate corrective actions**：已做或立即执行的具体动作（带时间或可验证项占位）。  
   - **Preventive measures**：制度、检查表、培训、供应商审核、列表审核流程等。  
   - **Closing**：请求恢复、愿配合补充材料。
3. **语言**：克制、专业、可执行；避免威胁、情绪辱骂、与平台对立表述。

## 硬性输出要求

同一回复内按顺序给出：

1. **Information gaps**：相对完整 POA 尚缺哪些字段（占位符列表）。
2. **Appeal subject line**（英文）：简洁。
3. **Appeal body**（英文）：分段完整正文，可直接粘贴或略改；含店铺/账号称呼占位与用户提供的标识。
4. **附件 / evidence checklist**（英文短列表）：如发票、授权书、包装图、培训记录等—**仅当用户业务真实存在时**勾选准备。
5. **中文摘要**：说明稿件结构、用户须自行替换的占位符、诚信提示。
6. **无 Emoji**。

若用户明确要求**全中文申诉**（少数入口或转述用），可提供中文版并注明「若目标团队为英文审核，需专业翻译核对」。

## 合规与禁忌

- **不伪造**订单、发票、品牌授权、物流记录。  
- **不教唆**隐瞒二次违规、绕过二审、多账户规避。  
- 不保证时间线（「三天必过」等）。
