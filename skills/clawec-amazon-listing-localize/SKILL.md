# 亚马逊 listing 主站 → 地方站转写

## 何时使用本技能

在需要把已在 **主站（常见为美国站 amazon.com）** 上架成功的 **标题、要点、描述、搜索词** 改编为 **日本站、欧洲站、澳大利亚站** 等本地语言 listing 时使用。本技能强调 **本地化改编**（含关键词与买家习惯），不是逐句机器翻译。

**范围**：文案与信息架构层面的转写流程；**不替代** 各站点 Seller Central 的合规审核、类目必填属性、认证资质（PSE、CE、能效标签等）——转写后须在目标站点后台核对政策与类目要求。

## 核心原则

1. **保留事实，改写表达**：品牌名、型号、SKU、可与官网一致的规格数字优先保留；营销句、俚语、仅适用于北美的场景词在目标市场重写。
2. **按目标站「买家检索习惯」选词**：日本站常混合 **汉字／假名／片假名外来语**（如 ワイヤレスイヤホン）；不能假设「把英文译成日语」就等于「日本买家会搜的词」。主关键词应参照目标站搜索结果页下拉与竞品高频写法（可由卖家用品牌分析/第三方工具验证）。
3. **单位与尺寸本地化**：北美常用英制（inch、oz、lb、°F）→ 日本/多数国际站用 **公制**（cm、mm、g、kg、ml、L、℃）。数值按当地阅读习惯四舍五入，并在描述中 **统一同一套单位**，避免混用。
4. **字符上限以目标站类目为准**：与通用上架规范一致——服装、婴童等类目标题上限可能更短；转写后必须在目标站点「添加商品」或模板中确认当前上限。
5. **合规用语因地而异**：避免绝对化治愈/疗效承诺、竞品名、站外导流；日本等对 **电器安全、无线电、儿童用品、食品表示** 常有单独表述要求，不确定则改用中性事实描述并提示卖家法务/客服确认。

## 北美 → 日本 转写清单

按顺序自检（可复制为任务列表）：

| 步骤 | 内容 |
|------|------|
| 1. 提取源文案结构 | 从主站复制 Title、Bullet 1–5、Description、A+ 文案要点、Backend search terms（如有）；记录必须保留的型号与认证写法。 |
| 2. 锁定 JP 主关键词 | 确定 3–8 个核心检索词（含片假名与汉字组合）；标题前部优先放 **最强检索词 + 品牌（如有）**，与主站顺序可能不同。 |
| 3. 标题改编 | 日语标题避免全部罗马字堆砌；适度使用买家会搜的片假名产品类目词；控制长度符合类目；不搞全角装饰符号或违规承诺。 |
| 4. 要点改编 | 每条一个清晰利益，顺序可按日本买家重视的 **安心・スペック・シーン** 微调；避免 Emoji 与过量特殊符号（与项目内英文 listing 技能一致的习惯：专业简洁）。 |
| 5. 描述与 A+ | 描述补充长尾场景与规格表（公制）；A+ 模块文案需单独翻译/改写，注意模块内字数与移动端阅读。 |
| 6. 单位与兼容表示 | inch→cm、oz→g 等；若商品为北美版插头/电压，须在日语中 **明确写明电压・プラグ形状・国内使用是否需要变压器**，避免客诉。 |
| 7. 合规与表示 | 需要展示的认证或法律条文以目标站现行要求为准；不确定时不要编造认证编号。 |
| 8. 后台搜索词 | 日本站「検索キーワード」规则与主站不同（重复、滥用品牌词等可能被限制）；填入 **日语词形变化与常见别字补全** 需谨慎，避免堆砌无关词。 |
| 9. 终检 | 与实物/包装/PDF 规格书核对数字；检查是否有仅英文残留（日本站正文应以日语为主）；检查禁售词与类目敏感词。 |

## 其他站点速查（简要）

- **欧盟/英国**：语言为各站目标语；除翻译外需关注 **GPSR、CE、EPR、能效标签** 等是否在文案或详情中有对应说明义务；英制/公制按当地惯例。
- **澳大利亚**：英语本地化（拼写、用语）；注意插头、合规与回收标识等地域要求。
- **加拿大（英法）**：若开魁北克等需求，可能需法语合规文案，与「美站英文」简单复制不同。

详细政策以 **各站点 Seller Central 帮助** 与 **库存文件模板说明** 为准。

## Agent 输出结构建议

当用户提供了主站 listing 全文并要求转写为日本站时，建议按序输出：

1. **Assumptions（若有）**：源站点、目标站点、用户是否允许省略部分规格、类目假设。
2. **保留项**：品牌、型号、不可替代的认证表述列表。
3. **Title（日语）**
4. **箇条書き（5 条，除非用户指定条数）**
5. **商品説明（日语段落）**
6. **キーワード対応表**：用户或源稿中的英文/中文核心词 → 日语采用写法与埋入位置说明（简述即可）。
7. **単位・仕様メモ**：若做了 inch→cm 等换算，单列一行说明换算依据（如「源稿 10 inch → 約 25.4 cm」）。
8. **リスク・要確認**：电压/插头/认证/类目专有必填等需卖家人工确认项。

**禁止**：编造未在源 listing 或用户提供的规格书中出现的数字与认证；不翻译竞品品牌名为「自家替代」。
