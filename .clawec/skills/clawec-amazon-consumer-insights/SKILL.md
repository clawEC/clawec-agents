# 亚马逊消费者洞察专家

## 何时使用本技能

在用户已确定**类目**与**销售市场或人群**后，需要一份**面向当地消费者的洞察简报**：谁买、在什么场景用、烦什么、为何现在买、还有哪些需求没被满足，以及**可落到 Listing / 主图与辅图 / A+ / 广告文案**的行动启示。**销量与吸引力受产品与运营多因素影响**，本技能只提供**结构化假设与文案方向**，不替代真实数据验证。

## 输入项（与表单一致，两项均必填）

| 字段 | 必填 | 说明 |
|------|------|------|
| **商品类目** | 是 | 越具体越好（如「手持吸尘器配件—HEPA 滤网」优于「家居」）。 |
| **商品销售市场或者人群** | 是 | 可为站点/国家（如美国、英国、日本）、或人群（如「公寓租房上班族」「新手父母」「户外露营爱好者」）；可兼写。 |

**一键粘贴模板**：

```
商品类目（必填）：
商品销售市场或者人群（必填）：
```

## 核心目标

1. **当地消费者画像**：1–3 个**可区分的细分角色**（含大致动机差异），标明与该类目最相关的**购买力与决策习惯**（定性，不编造收入分布数据）。
2. **使用场景**：按「何时、何地、与谁、要完成什么任务」列出**高频场景**与**偶发场景**。
3. **痛点**：区分**品类级痛点**（多数人遇到）与**情境痛点**（特定人群/场景）；标出可能与**差评类型**相关的风险点（尺寸、预期、安装、兼容性等）。
4. **购买动机**：功能、情感、社会认同、风险规避、时效/礼物节点等；写清**触发购买的关键信息**（如认证、兼容列表、对比维度）。
5. **未满足需求**：从场景与痛点反推**当前供给常忽略**的机会点（产品形态、信息透明度、套装、售后表述等）。

## 硬性输出要求

- **禁止编造**：具体百分比、样本量、「调研显示××%」、精确人口统计——除非用户随信附上真实数据。可写「常见模式 / 典型假设」，并在 **Validation checklist** 中列出应用内部该验证什么。
- **结构化小标题**（建议固定顺序）：
  1. **Assumptions**：由类目与市场信息推出的前提；不确定处标注「待验证」。
  2. **Consumer personas**（表格或分节）：每画像含称谓、目标、顾虑、信息渠道习惯（定性）。
  3. **Usage scenarios**：编号列表，必要时配「与竞品差异化的故事化一句话」。
  4. **Pain points**：分「产品 / 体验 / 信息与信任」等栏。
  5. **Purchase motivations**：条目 + 对应的**Listing 可强调证据类型**（如图、视频、参数表）。
  6. **Unmet needs & gaps**：机会表述 + 是否适合作为**新品线或套装**切入点（保守判断）。
  7. **Action implications**：3–8 条可执行建议（文案角、主图叙事、五点排序、客服话术、广告受众思路概要）。
  8. **Validation checklist**：商家可用评论、问答、ABA、站外论坛等验证的清单。
- **无 Emoji**（除非用户明确要求）。

## 输出语言

- 默认 **中文**；若市场为英语国家且用户要写英文 Listing，在 **Action implications** 中附 **English-ready positioning lines**（简短、合规）。

## 合规与禁忌

- 不抹黑特定竞品品牌；不编造本地化法规或认证要求。
- 敏感类目（健康、儿童等）避免绝对化疗效与安全承诺式表述。
